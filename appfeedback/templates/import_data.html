Import Instructions

📋 Before You Start

  • • Download the template files first
  • • Fill in all required columns
  • • Save files in Excel format (.xlsx or .xls)
  • • Ensure data accuracy before importing

✅ Import Order

  • • 1. Import Subjects first
  • • 2. Import Professors second
  • • 3. Import Students third
  • • 4. Import Practical Assignments
  • • 5. Import Theory Assignments
  • • 6. Create divisions/batches manually if needed

⚠️ Important Notes

  • • Duplicate entries will be skipped
  • • Invalid data will show error messages
  • • Check console messages after import
  • • Large files may take time to process
  • • Practical assignments link professors to batches
  • • Theory assignments link professors to divisions
  • • Both assignment types now require semester information
